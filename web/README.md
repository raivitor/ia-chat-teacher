# Ai Chat Teacher Web

Frontend em `Next.js 16 + React 19` (interface em português).

## Configuração

1. Copie `web/.env.example` para `web/.env.local`.
2. Ajuste `NEXT_PUBLIC_API_URL` se necessário (padrão: `http://localhost:3001`).

## Scripts

- `npm run dev`: sobe o frontend em modo desenvolvimento
- `npm run build`: gera o build de produção
- `npm run start`: sobe o build gerado
- `npm run validate`: roda lint, typecheck e testes unitários
- `npm run check`: roda `format:check`, lint e typecheck
